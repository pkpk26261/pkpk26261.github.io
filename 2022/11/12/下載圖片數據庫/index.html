Python 圖片蒐集：安裝工具與下載範例

2022.11.12黃永成約 2 分鐘閱讀更新於 2026.09.30

這篇記錄以 Python 工具蒐集圖片的方式，從套件安裝到腳本執行，保留一份可以查閱的操作範例。下載後仍需整理圖片內容與來源，才能放進後續的影像辨識工作流程。

本篇重點
  • 安裝圖片下載工具
  • 建立並執行下載腳本
  • 檢查下載結果，再整理成可使用的資料集

原始實作記錄於 2022 年；以下操作畫面與程式範例保留當時版本。

下方範例使用 simple_image_download，依關鍵字搜尋圖片並下載到電腦。它可以協助蒐集候選圖片，但下載結果仍需要人工檢查，不能直接視為可用的訓練資料。

安裝套件

以下指令固定使用原始範例的 0.4 版。先確認目前啟用的 Python 環境，再安裝套件，避免把工具裝到與執行腳本不同的環境。

建立下載腳本

範例中的 keywords 列出搜尋關鍵字，download 的第二個參數設定要下載的數量；原範例每個關鍵字設為 30。可以先用少量圖片確認流程，再依需求調整關鍵字與數量。

先在工作資料夾建立一個 dowmload_images.py 檔案

下載後的整理方式

先檢查輸出資料夾與實際取得的圖片，再刪除重複、損壞或與主題無關的檔案。若要投入模型訓練，還需要分類、標註與資料切分；搜尋關鍵字本身不等於圖片內容的正確標籤。

下載數量可能受到來源網站與套件版本影響，請以實際輸出為準。使用圖片前也要確認來源與可使用範圍。原始套件用法可查閱 simple-image-download 0.4 專案說明。
