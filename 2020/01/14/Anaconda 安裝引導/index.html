Anaconda 安裝紀錄：Windows 與 Linux

2020.01.14黃永成約 3 分鐘閱讀更新於 2026.09.30

Anaconda 是我建立 Python 開發環境時使用的工具之一。這篇分開整理 Windows 安裝介面與 Linux 終端機流程，並保留當時的截圖，方便對照每個階段。

本篇重點
  • 下載對應作業系統的安裝檔
  • 依 Windows 或 Linux 流程完成設定
  • 重新開啟終端機，確認 conda 環境已生效

原始實作記錄於 2020 年；以下操作畫面與程式範例保留當時版本。

以下分別記錄 Windows 與 Linux 的操作方式；畫面與版本保留當時的使用情境。

下載

至 Anaconda官網 https://www.anaconda.com/distribution/ 下載，
下載各系統所需且符合處理器架構的安裝檔後，再依 Windows 或 Linux 段落操作；畫面可能因版本而異。

Windows 10

下載完成後執行 Windows 安裝程式，依下方畫面核對各階段。

  1. 選擇Next> (下一步>)

  2. 閱讀授權條款；同意後選擇 I Agree（我同意）。

  3. 此紀錄選擇 Just Me（僅目前使用者）。若要讓所有使用者共用，需依電腦權限與使用情境另行選擇。

  4. 選擇Anaconda安裝路徑，再點選Next> (下一步)

  5. 查看 Advanced Options（進階選項），確認 PATH 與預設 Python 的設定是否符合需求，避免與既有 Python 安裝混淆。

  6. 等待安裝過程

  7. 安裝過程結束後，點選Next> (下一步)

  8. 點選Next> (下一步)

  9. 點選Finish (完成)

  • 安裝完成（Anaconda Prompt初始介面）

Linux

以下使用當時的 python3.7 安裝檔示範；python2.7 的提及保留為歷史紀錄。重做安裝時請使用實際下載的檔名，並依專案需求選擇版本。

  • 安裝指令

  1. 輸入上方的安裝指令

  2. 請按ENTER繼續

  3. 依原安裝程式的提示按任意鍵閱讀授權條款；實際閱讀操作以終端機顯示為準。

  4. 您接受許可條款嗎？[是|否]確認接受條款後，輸入 yes 繼續。

注意

  1. 每次按 ENTER 確認一個提示後，再閱讀下一個選項，避免連續按鍵意外接受未確認的路徑或設定。若跳過某個提示，先確認安裝位置、終端機輸出與初始化結果，再決定是否需要調整設定或重新安裝。

  2. 通過運行conda init？ [是|否]若希望這個 shell 能啟用 conda，可依提示輸入 yes 進行初始化；完成後重新開啟終端機。

  • 安裝完成
  • 重新開啟終端機，確認 conda 指令能正常執行，並查看版本與環境清單。提示列出現（base）只表示該環境已啟用，不能單靠它判定所有套件都正常。

安裝後先確認哪幾件事

先查看 conda 版本與目前環境，再啟動 Python 確認版本和執行檔位置。若系統原本已有 Python，檢查編輯器選用的解譯器是否與 Anaconda 一致，之後再安裝專案需要的套件。
