Anaconda 指令速查：套件、環境與 Notebook

2020.01.14黃永成約 3 分鐘閱讀更新於 2026.09.30

這篇把日常使用的 conda、pip 與 Jupyter Notebook 操作整理成速查筆記。從查看版本、建立環境到安裝套件，先分清楚目前使用的環境，再執行對應指令。

本篇重點
  • 查看版本並管理 conda、pip 套件
  • 建立、啟用、離開與移除虛擬環境
  • 選擇 Python 執行方式並使用 Notebook 快捷鍵

原始實作記錄於 2020 年；以下操作畫面與程式範例保留當時版本。

以下依套件管理、環境管理與 Notebook 操作分類，方便日後查閱。

請至 Anaconda 官網 下載安裝應用程式。

Anaconda 管理模組

  1. 模組安裝
    pip主要管理 Python 套件，也會處理套件宣告的相依項目： conda管理環境與套件，也會解析相依項目。安裝前先確認目前環境及套件來源：
  2. anaconda 升級
  3. pip 升級

安裝及更新conda

  1. 查看conda版本
  2. conda 更新

建立虛擬環境

先建立獨立環境，再啟用並安裝套件。範例中的 name 代表環境名稱；Python 3.6 是原紀錄的版本，重做時依專案相依條件選擇。移除環境前，先確認名稱與需要保留的套件清單。

  1. 查看目前有哪些環境
  2. 建立名為虛擬環境(name為自定義名稱)，並且安裝為python3.6版本。
  3. 啟動環境(name為要啟動的環境名稱)
  4. 離開環境
  5. 刪除環境(name為該環境名稱)

選擇 Python 執行方式

從命令列執行 Python 互動式Shell

C:\Users\user>python：進入互動模式，逐段測試並立即查看結果，適合簡短驗證；較長的程式建議保存成檔案。

從檔案執行Python

C:\Users\user>python test.py：執行已保存的完整程式，方便反覆編修；也能透過輸出與除錯工具查看結果。

Jupyter Notebook 編輯器

啟動Jupyter Notebook編輯器的方式有兩種，

  1. 在Anaconda Prompt下打入jupyter notebook
  2. 點選桌面的應用Jupyter Notebook

常用熱鍵

以下是本文使用的傳統 Notebook 介面快捷鍵。注意編輯模式與命令模式的差別；其他版本若操作不同，可從介面的快捷鍵說明查閱。

  1. Shift + Enter：執行目前儲存格並移到下一格；位於最後一格時，會新增儲存格。
  2. Ctrl + Enter：執行目前儲存格，停留在原位置。
  3. 先按 Esc 進入命令模式，再按 A：在上方插入儲存格。
  4. 先按 Esc 進入命令模式，再按 B：在下方插入儲存格。
  5. 先按 Esc 進入命令模式，再連按兩次 D：刪除儲存格。
  6. 先按 Esc 進入命令模式，再按 H：查看快捷鍵。

指令執行前的確認

安裝成功卻無法匯入套件，常需要先核對安裝位置與執行程式使用的解譯器。Notebook 也有自己的 kernel；終端機啟用某個環境，不代表已開啟的 Notebook 會自動切換到它。
