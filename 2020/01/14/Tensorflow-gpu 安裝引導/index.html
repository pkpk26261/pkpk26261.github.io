TensorFlow GPU：Anaconda 舊版環境安裝紀錄

2020.01.14黃永成約 2 分鐘閱讀更新於 2026.09.30

這篇保留當時在 Anaconda 中建立 Python 3.6 環境與安裝 tensorflow-gpu 的流程。它適合查閱舊專案的環境設定；套件名稱、GPU 支援方式與相依版本，需以所使用版本的文件為準。

本篇重點
  • 建立並啟用獨立的 Python 環境
  • 安裝當時使用的 TensorFlow GPU 套件
  • 了解套件與整個環境的移除方式

原始實作記錄於 2020 年；以下操作畫面與程式範例保留當時版本。

以下整理當時使用 conda 的操作順序。這是 Python 3.6 與 tensorflow-gpu 的舊版環境紀錄，不是新版 TensorFlow 的通用安裝方式。

<name>代表自行命名的環境

  1. 建立 Python3.6 新環境

  2. 啟動<name>環境

  3. 啟用目標環境後，安裝當時使用的 tensorflow-gpu。conda 依套件來源解析相依項目；CUDA 與 cuDNN 的對應版本仍需確認，系統顯示卡驅動也要另行檢查。
