本篇重點

常用快捷鍵

  1. 新增新專案
    在該專案裡面，按Ctrl + Shift + N，即可跳出建立新專案的視窗。
  2. 新增檔案
    在專案中按Ctrl + N，可開啟新增檔案的視窗。
  3. 加入新增專案項目

變數的命名規則

資料參考專案 Learning 03。

  1. Pascal 帕斯卡命名：當有多個單字組成變數或方法時，每個單字的開頭字母要大寫。
    (常用處：類名、屬性、方法名、介面)
  2. 駝峰命名：多個單字出現，首單字開頭字母要小寫，其餘單字開頭字母要大寫。
  3. C# 變數：常見命名使用字母、數字與底線，首字元不能是數字，並避開保留字。C# 也支援部分 Unicode 字元；入門練習先採用清楚、一致的英文名稱。

存取修飾符

修飾詞決定哪些程式碼可以使用型別或成員。internal 的邊界是組件，而不是命名空間；同名命名空間不表示一定有權限存取。

操作說明

存取權限

  1. private：私有的，僅類的內部程式可以使用
  2. protected：受保護的，類的內部和繼承子類可以存取。
  3. internal：內部的，可由同一個組件（assembly）中的程式碼存取。
  4. public：公共的，完全公開，沒有存取限制。

練習時先改變一個條件，再觀察編譯訊息或執行路徑，會比只記名稱更容易理解。

VS除錯Bug的方法

先在條件判斷前設斷點，查看變數，再用 F10 或 F11 追蹤下一步。預測哪一個分支會執行，再與除錯結果對照。

  • 三種常用的除錯操作
  1. F5：啟動或繼續執行，直到遇到斷點或程式結束。
    斷點方式：在VS 2019中，點選程式行左側的邊界，或使用 F9 切換斷點；紅色圓點表示斷點已設置。
  2. F10：逐程序執行（Step Over），通常不進入呼叫的方法。
  3. F11：逐步執行（Step Into），可進入呼叫的方法。

練習時先改變一個條件，再觀察編譯訊息或執行路徑，會比只記名稱更容易理解。

值類型
  • C# 支援下列預先定義的整數型別：
    C# 型別/關鍵字 範圍 大小 .NET 類型
    sbyte -128 到 127 帶正負號的 8 位元整數 System.SByte
    byte 0 至 255 不帶正負號的 8 位元整數 System.Byte
    short -32,768 至 32,767 帶正負號的 16 位元整數 System.Int16
    ushort 0 到 65,535 不帶正負號的 16 位元整數 System.UInt16
    int -2,147,483,648 至 2,147,483,647 帶正負號的 32 位元整數 System.Int32
    uint 0 到 4,294,967,295 不帶正負號的 32 位元整數 System.UInt32
    long -9,223,372,036,854,775,808 至 9,223,372,036,854,775,807 帶正負號的 64 位元整數 System.Int64
    ulong 0 到 18,446,744,073,709,551,615 不帶正負號的 64 位元整數 System.UInt64
