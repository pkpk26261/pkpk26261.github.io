Ubuntu 與 Windows 雙系統：安裝流程紀錄

2020.05.03黃永成約 4 分鐘閱讀更新於 2026.09.30

這篇以當時使用的 Ubuntu 20.04 與 Windows 10 為例，記錄開機 USB、磁碟分割、系統安裝與 GRUB 設定。安裝前先確認備份與目標磁碟，再依實際電腦的分割區配置閱讀步驟。

本篇重點
  • 下載 ISO 並製作安裝 USB
  • 確認磁碟分割後，從 USB 啟動安裝
  • 安裝完成後檢查開機選單與時間設定

原始實作記錄於 2020 年；以下操作畫面與程式範例保留當時版本。

依序完成安裝媒體、磁碟配置、系統安裝與開機選單設定。安裝畫面以當時的測試環境為例。

下載ISO光碟映像檔

至 Ubuntu 正體中文站 https://www.ubuntu-tw.org/modules/tinyd0/ 下載，
選擇所需版本；本文當時使用的是 20.04 LTS（本文 2020 年的版本紀錄，實際支援條件請查閱所用版本文件）。

ISO to USB

至 Rufus 官網 https://rufus.ie/ 下載應用程式。

開始將 ISO 寫入USB

注意以下步驟將會格式化USB的資料，請備份USB內資料或使用空的USB。

  1. 先選擇要寫入的 USB，再於「開機選擇」載入 Ubuntu ISO。這裡製作的是 Ubuntu 安裝媒體，不是 FreeDOS 開機碟。

  2. 再選擇剛下載好的 Ubuntu ISO 映像檔，選擇完後，核對 USB 裝置、ISO 檔案與目標電腦的開機方式，再按「執行」。截圖中的設定只是當時的配置，不必逐項照抄。

  1. 若出現「建議選項」等寫入模式提示，先閱讀說明，再依 ISO 與 Rufus 提示選擇，確認後按 ok。清除資料前，再次核對目標 USB。

分割硬碟

本段是在 Windows 中預先保留雙系統所需空間。若只安裝 Ubuntu，可依安裝程式安排分割區，但仍需確認是否會清除原有資料。進入Windows 10 硬碟管理，依硬碟容量與軟體需求安排空間。我當時為根目錄(/)預留至少 50 GB，家目錄(Home)的容量則依個人資料量安排；這不是固定配置。當時採用 100GB(SSD) 加 400GB(HDD) 分開配置，這些數字只說明我的安裝方式。配置中，100 GB 掛載於根目錄(/)，400 GB 用於家目錄(Home)，實際掛載點為 /home。這是把系統與個人資料分開保存，不等同於 Windows 磁碟代號。

進入BIOS選擇 USB 為啟動硬碟

不同主機板的 BIOS／UEFI 畫面與開機選單按鍵各異，本文未附這部分的操作截圖。可依電腦型號查閱原廠開機說明，或用 Google 搜尋「BIOS選擇USB」並加上型號，選擇剛製作的安裝媒體。

選擇其它

「清除磁碟並安裝Ubuntu」會移除所選磁碟原有內容；只有確定要用 Ubuntu 取代該磁碟上的系統與資料時，才適用。保留 Windows 的配置需另外確認分割區。

選擇硬碟

以下分割區畫面來自 VMware，因此容量與實際電腦的配置不同。請以自己磁碟的名稱、容量及用途辨認目標分割區。選擇剛分割好的硬碟，點選左下 + 符號，建立分割區，詳情請看圖。配置中，100 GB 掛載於根目錄(/)，400 GB 用於家目錄(Home)，實際掛載點為 /home。這是把系統與個人資料分開保存，不等同於 Windows 磁碟代號。

設定用戶及密碼

設定登入帳號與密碼，並記下自己的使用者名稱。完成安裝後，分別啟動 Ubuntu 與 Windows，確認兩個系統都能正常進入，再檢查原有資料與網路連線。

等待安裝過程

安裝完成，重啟電腦

拔除USB

此步驟可安全拔除USB，拔除後，按Enter重啟後便安裝完成。

開機選單

雙系統安裝完成後，會有開機選單。截圖中可選擇 Ubuntu、Windows 或韌體設定；項目的數量與順序會隨電腦配置改變。

單系統的選單依安裝設定而異。單系統也可能顯示 Ubuntu 與韌體設定等項目，請依選單名稱辨認。

更改預設開機項目

查看windows位址

  • 首先要先知道自己的 Windows 系統的開機名字和裝在哪個磁碟，所以打入上述指令並且複製引號內的文字供等會使用。

更改配置

接著用指令打開 GRUB 的設定檔，
將 GRUB_DEFAULT=0 後方的數值改為剛剛複製的 Windows 開機名稱後儲存，如下圖所示。

更新設置

這裡提供另一個方法，就是進入 BIOS 直接改變開機順序，將預設第一順位改為 Windows Boot Manager。

  • GRUB 設定需執行前述更新指令後才會生效；直接調整 BIOS／UEFI 順序則是另一條路徑。兩者控制的層次不同，請依實際開機流程選擇。

處理 Windows 與 Ubuntu 的系統時鐘差異

雙系統時間偏移可能與硬體時鐘採用 UTC 或本地時間有關，不一定是時區選錯。下方保留當時採用的指令；調整前先檢查兩個系統的時間、時區與時鐘設定。

安裝後的確認順序

先確認開機選單能分別進入兩個系統，再查看磁碟掛載、個人資料與時間是否符合預期。若其中一個系統無法啟動，先記錄選單內容與錯誤訊息，避免在尚未辨認磁碟的情況下重新分割。
