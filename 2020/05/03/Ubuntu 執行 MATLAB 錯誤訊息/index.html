Ubuntu 啟動 MATLAB：canberra-gtk-module 錯誤處理

2020.05.03黃永成約 2 分鐘閱讀更新於 2026.09.30累計閱讀 統計中…次

在 Ubuntu 啟動 MATLAB 時，若出現 canberra-gtk-module 相關訊息，可以先檢查相依套件，再確認啟動時使用的環境變數。這篇區分單次啟動與持續套用的設定，方便選擇適合的處理方式。

本篇重點
  • 確認啟動訊息與所缺少的套件
  • 以單次環境設定測試是否改善
  • 確定有效後，再評估是否寫入啟動設定

原始實作記錄於 2020 年；以下操作畫面與程式範例保留當時版本。

啟動 MATLAB 時若出現 {Failed to load module "canberra-gtk-module"}，先確認程式是否仍能開啟。這則模組載入訊息本身不一定代表啟動失敗；若還有其他錯誤，應分開記錄與排查。

如何判斷是否改善

再次從終端機啟動 MATLAB，對照原本的訊息，並實際開啟命令視窗、執行簡單運算。若訊息消失但功能仍異常，或訊息存在卻不影響操作，都應分開記錄，不要只用單一訊息判定成功與失敗。
