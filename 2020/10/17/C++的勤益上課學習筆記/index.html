這份筆記整理勤益課程中的 C++ 基礎與練習題，包含資料型態、格式化輸出、條件判斷、迴圈與函式。內容依上課日期與題號排列，可以先查語法，再回到對應的程式範例與輸出結果。

變數名稱

變數名稱可以是英文字母、數字或底線

  • 名稱中不能有空白字元
  • 第一個字元不能是數字
  • 不能使用到關鍵字

格式化輸出的使用

  1. %d：以十進位輸出 int。格式指定符本身不決定型態大小，int 的儲存空間依編譯器與平台而定。
  2. %u：以十進位輸出 unsigned int。要與實際傳入的型態相符。
  3. %o：以八進位輸出 unsigned int。
  4. %x：以十六進位輸出 unsigned int。
  5. %f：printf 中用於輸出浮點數；scanf 的 %f 與 %lf 則需分別搭配 float 與 double 的位址。
  6. %s：輸出以空字元結尾的字串。
  7. %c：輸出單一字元。
